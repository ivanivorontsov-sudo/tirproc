# Тирпроц

Офлайн-редактор тир-листов. Картинки и доски лежат в IndexedDB браузера, на сервер ничего не уходит.

Как устроены нормальные тир-листы: ряд — это уровень, карточка — объект ранжирования, запас — ещё не разложенное. Перетаскивание между рядами, свои цвета и подписи, экспорт картинки и файла данных. Аккаунт и общая база тут не нужны: список живёт у того, кто его собирает.

## Что умеет

- несколько проектов в одном браузере
- шаблоны: классика S–F, фильмы, игры, еда
- текстовые карточки и картинки (файл, перетаскивание, вставка из буфера)
- ряды: добавить, переименовать, перекрасить, сдвинуть, удалить
- поиск и перемешивание запаса
- отмена и возврат
- сводка по рядам
- скачать PNG доски
- скачать и открыть JSON вместе с картинками

## Запуск

Открой `index.html` в браузере. Сервер не нужен.

Репозиторий: https://github.com/ivanivorontsov-sudo/tirproc
