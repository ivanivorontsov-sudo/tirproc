# Сторонние компоненты

Исходный код в репозитории не содержит чужого кода, шрифтов, иконок, изображений и звуков. Шрифты берутся из системы пользователя и не распространяются.

Установщик для Windows включает:

| Компонент | Лицензия | Источник |
| --- | --- | --- |
| Electron | MIT | https://github.com/electron/electron/blob/main/LICENSE |
| Chromium (в составе Electron) | BSD-3-Clause и другие, полный список в файле LICENSES.chromium.html внутри установленной программы | https://www.chromium.org/ |
| electron-builder (сборка установщика) | MIT | https://github.com/electron-userland/electron-builder |

Qwen и chat.qwen.ai являются сервисом и обозначениями их правообладателя. Тирпроц не связан с ним и только открывает его страницу во встроенном окне. Для работы нужен собственный аккаунт пользователя и соблюдение правил сервиса.
